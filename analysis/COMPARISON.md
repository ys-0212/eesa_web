## 3. Remaining differences (known, documented)

### Content / licensing (intentional)
- **All media replaced** with original SVGs (`public/media/**`, generated by `scripts/media/generate.mjs`): case-study photos,
  article thumbnails, 13 service illustrations, testimonial portraits, client logos, partner badges/icons, the ring images and the
  3D pigeon mascot ("Frankie" → original character "Pip"). Reasons in `SPEC.md §4`.
- **Copy replaced** with original placeholder text of similar length; client names, people, quotes and metrics are fictional and
  marked as such in `src/content.ts`. Generic UI labels (nav items, buttons, footer headings) are kept.
- **Fonts substituted**: Perfectly Nineties → Instrument Serif, articulat-cf → Figtree, script logo → Yellowtail (Space Mono kept).
  Instrument Serif is close in proportion; Figtree is slightly wider than articulat-cf; Yellowtail is a different script, so the
  nav wordmark (≈ 140 px wide vs 149 px) and the giant footer wordmark differ in letterforms.
- The logo is set as text unless `site.logo` is provided (then any SVG/PNG logo is used).

### Layout
- 1024 / 768: research, services and testimonial blocks are 30–150 px shorter because the placeholder headings/quotes wrap to fewer
  lines than the reference copy. With the real copy and fonts the measured rules (61.5 % heading width, fluid rem scale, gutters)
  reproduce the reference wrapping.
- 390 / 768 testimonials: the reference block is sized to its longest (13th) quote; the clone uses the same "tallest slide" rule
  with 6 placeholder quotes, so it is shorter (−155 to −196 px).
- Hero at 390/768 is ~30 px taller (lead wraps to one more line in Figtree).
- The menu sitemap card omits the mascot peeking from the bottom edge.

### Motion
- **Ring (A10)**: the reference renders curved textured panels with Three.js r128 on a canvas; the clone uses flat CSS-3D panels on a
  cylinder (same 8 panels, continuous Y rotation, camera slightly below, scroll boost). Panels are flat, not curved.
- **Collaborator cursor (A4)**: waypoints approximated from the recording; exact easing/path of the reference loop not extracted
  (its GSAP timeline is not a ScrollTrigger and could not be read from `ScrollTrigger.getAll()`).
- **Text reveals (A1)**: same parameters as the reference's 77 triggers (lines masked, y 100%→0, .6 s power2.out, stagger .1,
  `top 95%`, once) using GSAP SplitText instead of SplitType.
- **Count-up (A7)**: duration 1.6 s power2.out — the reference Flowbase booster's exact duration was not measured.
- **Smooth scroll (A2)**: Lenis 1.3 with `lerp .1` vs reference Lenis 0.2.28 defaults; feel is equivalent, wheel deltas are not
  clamped to 100 px the way the reference's old Lenis build does.
- Service-card and case-card hover zoom (scale 1.04) is an approximation; the reference hover could not be captured with the card
  under the pointer in the headless run (`interactions/hover-case-card.png`).
- Not reproduced (out of scope / third-party): CookieYes consent banner, Intellimize personalisation, reCAPTCHA/Turnstile, contact
  modal (Finsweet modal) — the CTA buttons link to `#contact`.
